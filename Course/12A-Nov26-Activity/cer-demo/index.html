Why might another tool show different edits?

Some texts have several comparisons with the same minimum number of edits. A tool may choose different substitutions, deletions, or insertions, while the total and CER stay the same. Different text-cleaning rules can also change the score.

We count Unicode code points, as Python strings do. In Khmer, emoji, and text with combining marks, one visible symbol may contain several code points. We preserve the text without Unicode normalization.

A QUICK GUIDE

Three ways text can change.

Each edit costs one. A matching character costs zero. We find the fewest edits from reference to prediction.

S

Substitution

A character is replaced.

cat → cut
D

Deletion

A reference character is missing.

cat → ct
I

Insertion

An extra character is added.

cat → cart
!

A small error can change a big fact.

“4 years” and “5 years” differ by one character. CER measures that difference; it cannot decide which statement is true. Use it alongside a review of meaning and facts.
